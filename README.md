## Featured Projects

### Biologically-Inspired Adaptive Exploration for AI Agents
**Final Year Individual Dissertation**

A reinforcement learning research project investigating whether biologically inspired reward-prediction mechanisms can improve exploration in deep reinforcement learning agents.

The approach combines **Bootstrapped DQN**, **Random Network Distillation (RND)**, ensemble-based uncertainty estimation, and a biologically inspired reward prediction error mechanism to dynamically influence learning behaviour and exploration.

**Technologies:** Python, PyTorch, Gymnasium, Deep Reinforcement Learning

[View Repository](https://github.com/FadilahSyed/FYP-Dopamine-Inspired-RL)

### Oil Palm Seed Quality Classification
**Computer Vision Project**

Developed a deep learning pipeline for classifying germinated oil palm seeds as good or defective, with emphasis on model robustness under real-world changes in lighting and pose.

The project uses **ResNet18 transfer learning**, Grad-CAM explainability, systematic error analysis, and augmentation-based improvements to evaluate and address performance degradation under distribution shift.

**Technologies:** Python, PyTorch, ResNet18, Computer Vision, Grad-CAM

[View Repository](https://github.com/FadilahSyed/Oil-Palm-Comp-Vis-Claassifier)

### Luxury Passport
**Hackathon Project — Digital Commerce and Blockchain**

A prototype digital product passport for luxury goods, combining an e-commerce interface with blockchain-based product records.

The system supports Dash-based payment verification while a backend service records NFT metadata on an Ethereum-compatible blockchain, enabling product information such as material, condition, and transaction details to be stored on-chain.

**Technologies:** JavaScript, Node.js, Express, Solidity, Hardhat, ethers.js

[View Repository](https://github.com/kellyyngu/nottsHack2)

### Shakespeare 3D
**Software Engineering Group Project**

A Unity-based 3D application for creating, editing, and visualising Shakespearean scenes in an interactive virtual environment.

The system supports script selection, character positioning, multiple camera modes, undo/redo functionality, scene persistence using JSON, and guided tutorials. The project was developed collaboratively as part of a six-person software engineering team.

**Technologies:** Unity, C#, 3D Development, JSON, Software Engineering
